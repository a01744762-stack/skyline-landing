# Skyline Rocketry Landing Page 🚀

Landing page minimalista e interactiva creada para el proyecto aeroespacial **Skyline (Wan Hu 67 | Sinaloa - 2026)**.

## 🛠️ Tecnologías Utilizadas
- HTML5
- CSS3 (Variables, Flexbox, Glassmorphism, CSS Animations)
- JavaScript

## 📦 Estructura del Proyecto
- `index.html`: Estructura principal de la página.
- `style.css`: Estilos visuales en tema oscuro minimalista espacio.
- `script.js`: Archivo JavaScript para interacción.
- `logo.png`: Logotipo oficial del proyecto.

## 🚀 Publicación rápida en GitHub Pages
1. Sube los archivos a tu repositorio de GitHub.
2. Ve a **Settings** -> **Pages**.
3. Selecciona la rama `main` y guarda.
4. ¡Listo! Tu página estará en vivo en minutos.
